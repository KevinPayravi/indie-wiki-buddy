4.0 Update: Re-enable Your Preferences!

Sorry to interrupt, but this is a one-time notice about an important update for Indie Wiki Buddy!

Previously, Indie Wiki Buddy had access to all search engines by default, for filtering search results and directing you to indie wikis. Now, search engine filtering is now only enabled by default for google.com, and opt-in for all other search engines. Depending on your browser, you may need to re-enable and re-grant permissions for the search engines you'd like Indie Wiki Buddy to work with below. If the search engine(s) you want are already checked, you're good to go.

This change has been done to make Indie Wiki Buddy more privacy-friendly, and enables us to add support for more search engines in the future without having to annoy you with pesky permission requests when updating.

🔍 

In addition, BreezeWiki permissions have been reworked. If you were previously using a BreezeWiki mirror, you may need to re-grant permissions for it.

🍃 

For all changes in v4.0, visit the changelog.
